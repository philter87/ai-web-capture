Page Capture

Grab a region of any page as a PNG plus its HTML, write a description, and save both into the folder you keep a Claude session in. On GitHub it fills a new issue from a saved capture instead.

This installs like a bookmark, not an app — drag the button below up into your browser's bookmarks bar. Clicking it here won't do anything.

Capture

First run

  1. Show the bookmarks bar (Cmd/Ctrl+Shift+B).
  2. Click Capture on any page — a panel appears bottom right.
  3. The first capture asks to share a tab. Pick This tab.
  4. Saving asks for a folder. Pick the folder your Claude session runs in.
