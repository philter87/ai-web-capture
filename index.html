First run

  1. Show the bookmarks bar (Cmd/Ctrl+Shift+B).
  2. Click AI Web Capture on any page — a panel appears bottom right.
  3. The first capture asks to share a tab. Pick This tab.
  4. Saving asks for a folder. Pick the folder your Claude session runs in.
